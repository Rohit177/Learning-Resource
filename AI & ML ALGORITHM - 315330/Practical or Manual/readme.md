## 📚 Repository Overview

This folder contains syllabus-aligned practical programs, laboratory experiments, and case studies for the **Artificial Intelligence & Machine Learning (AI & ML)** course. The practicals provide hands-on experience in AI search algorithms, reasoning techniques, Machine Learning workflows, model building, and performance evaluation using Python.

---

## 🎯 Laboratory Learning Outcomes (LLOs)

* **LLO1:** Install and configure Python IDE and ML libraries.
* **LLO2:** Implement AI search algorithms.
* **LLO3:** Analyze datasets and AI case studies.
* **LLO4:** Develop supervised and unsupervised ML models.
* **LLO5:** Evaluate ML models using standard metrics.

---

# 📌 Practical-wise Coverage

## 🔹 Practical 1 – Environment Setup

Install Python IDE, configure the development environment, and set up Scikit-Learn for Machine Learning experiments.

📌 **Mapped CO:** CO1

---

## 🔹 Practical 2–5 – AI Search Algorithms

Implement uninformed and informed search techniques including Breadth First Search (BFS), Depth First Search (DFS), Greedy Best-First Search, and A* Search Algorithm.

📌 **Mapped CO:** CO1

---

## 🔹 Practical 6–7 – Reasoning & AI Concepts

Implement Bayes' Theorem and analyze the Turing Test through case studies to understand reasoning and intelligent behavior in AI systems.

📌 **Mapped CO:** CO2

---

## 🔹 Practical 8–10 – Dataset Analysis & Preparation

Explore datasets using Kaggle and Google Dataset Search, perform train-test splitting, and analyze email spam classification using Machine Learning techniques.

📌 **Mapped CO:** CO3

---

## 🔹 Practical 11–13 – Machine Learning Models

Implement Decision Tree Classification, K-Means Clustering, and Cross-Validation techniques to build and validate Machine Learning models.

📌 **Mapped CO:** CO4

---

## 🔹 Practical 14–16 – Regression & Evaluation

Develop Simple and Multiple Linear Regression models and evaluate classification performance using Confusion Matrix and related metrics.

📌 **Mapped CO:** CO5
